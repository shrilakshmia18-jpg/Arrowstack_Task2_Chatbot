# 🤖 ARROWSTACK AI – Intelligent Chatbot Agent

## 📌 Project Overview

This project is an intelligent chatbot developed as part of the **Arrowstack Artificial Intelligence Internship – Task 2**.

The chatbot combines **rule-based responses** with **TF-IDF similarity matching** to understand user queries and provide appropriate responses.

A professional web interface is developed using **Flask, HTML, CSS, and JavaScript**.

---

## 🎯 Objectives

- Develop an intelligent chatbot using Python
- Implement rule-based conversation handling
- Implement TF-IDF similarity-based query matching
- Create a user-friendly web interface
- Build a real-time chatbot API using Flask
- Provide responses for common AI and programming-related questions

---

## ✨ Features

- 🤖 Intelligent chatbot interaction

- 💬 Real-time chat interface
